# PlaceBridge 🚀
Bridging Students to Placement Opportunities

## 📌 Description
PlaceBridge is a web-based platform that helps students check placement eligibility, apply for jobs, and track their application status in one place.

## ❗ Problem
Students miss placement opportunities due to scattered information and manual eligibility tracking.

## 💡 Solution
A centralized system to:
- Check eligibility instantly  
- View job opportunities  
- Apply for roles  
- Track applications  

## ✨ Features
- Eligibility Assistant  
- Best Job Matches  
- Application Tracking  
- Instant Updates  

## 🛠️ Tech Stack
- Frontend: HTML, CSS, JavaScript  
- Backend: (Planned) Node.js  

## 🔄 Workflow
Profile → Eligibility → Apply → Shortlist → Interview → Result  

## 🚀 Future Scope
- AI-based job recommendations  
- Resume analysis
